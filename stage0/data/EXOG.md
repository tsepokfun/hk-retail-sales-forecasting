## 3. Judgement calls

**J1 — CPI series choice.** `510-60001A` mixes four index families (`A_CM_1920`, `B_CM_1920`, `C_CM_1920`, `CC_CM_1920`) × ten commodity groups × three `svDesc` measures. The **composite** CPI is `CC_CM_1920`; the all-items total is `GROUP=''` with `GROUPDesc='Total'`; `svDesc='Index'` is the level series (the table also carries its own `Year-on-year % change` and `Month-to-month % change` columns, which are NOT used — the spec transforms the level itself).

**J2 — which months the rate z-score is fitted on.** `BL_RATE` runs back to 1980, but "train" in this project means the model's training months, i.e. the panel window `200410`..`202312` (231 months). The scaler therefore uses mu=5.4158%, sigma=0.8828pp. Fitting on 1980-2023 instead would mix in the 1980s double-digit rates and stretch the z-scale for no modelling benefit. No post-202312 data is used either way.

**J3 — EERI variant.** `340-46002` carries `EERI_T` (trade-weighted), `EERI_I` (import-weighted) and `EERI_E` (export-weighted). The trade-weighted total is the standard competitiveness measure and the one the spec asks for; as a check `EERI_T` sits inside `[min(EERI_I, EERI_E), max(EERI_I, EERI_E)]` in all 621 monthly observations, i.e. it behaves like the aggregate.

**J4 — visitor arrivals.** `REGION=''` (`REGIONDesc='Total'`) is the all-region total, not a source market; it equals the sum of the 11 named regions exactly in all 272 months. The series starts in `200401`, so `visitor_yoy` needs `200401`+12 months of history and is therefore NaN for `200410`..`200501` (4 leading months). `log1p` is used because arrivals can in principle be zero; the observed minimum is 1,800 (COVID), so no zero handling was triggered. COVID collapse + recovery makes this the only feature whose range leaves ±5 (see §2).

**J5 — cargo.** Kept the level series (`svDesc="('000 tonnes)"`), not the table's own `Year-on-year % change`; kept `DIRECTION=''` (Total) and `SHIPMENT_TYPE=''` (Total) because In/Out and DS/TS partition the total. The total equals Inward+Outward to within 1 thousand tonnes (rounding) in all 355 months. The published level series currently ends at `202607`, one month short of the panel end; `cargo_yoy` at `202608` is still computable because it only needs the `202607` level and its `202507` comparison.

**J6 — MTR.** `Domestic Service Monthly Total` is column index 1, in **thousands** of passenger trips; commas stripped, `-` (no service) -> NaN. The file was parsed to 320 monthly rows, `200001`..`202608` (the brief said 327 lines / May 2000: the extra lines are the title, two header rows and two footnotes, and the oldest month is actually January 2000). Values are multiplied by 1000 before logging; this only affects the `+1` inside `log1p` (not used here) and is otherwise scale-free.

**J7 — rainfall `Trace`.** `Trace` = rain too small to measure. Mapped to **0.05 mm**, the HKO convention for a trace amount, and documented here. There are 26 such cells in the whole 1884-2026 file; within the panel window the affected months are listed implicitly by a rainfall value of 0.05. `***` = missing -> NaN. Trailing `#` markers (provisional figures, seen on 2026-08) are stripped.

**J8 — weather is not shifted.** A month's mean temperature and total rainfall are fully observed when the month closes, so `rain_anom_z` / `temp_anom_z` are aligned to the same month. The macro series are official statistics published with a lag, so they are shifted by one month: month t uses the value published for t-1.

**J9 — standard deviation.** `std(ddof=0)` (population std), matching `data/make_features.py`, which uses `logs.std(ddof=0)` for `scaling.csv`. Stated here because `pandas.Series.std` defaults to ddof=1.

**J10 — no imputation.** Nothing is filled, interpolated or clipped. NaNs are kept so the downstream window builder can drop incomplete windows honestly; the only NaN region that matters is the 4 leading `visitor_yoy` months, which sit in the first few 12-month context windows.

## 4. Known limitations worth remembering

- `visitor_yoy` during the 2020-2023 border closure spans roughly -7.21 .. +7.22; that is the true YoY, not a bug, but it dominates the scale of group B.
- `cargo_yoy` at `202608` uses the `202607` cargo level (the last published month); from `202609` onwards the feature would be NaN.
- The published `Year-on-year % change` column of `510-60001A` does not reproduce `log(cpi)-log(cpi-12)` exactly (mean |diff| ~0.1pp, max 0.77pp in-window) because the index published in the API is rounded to one decimal and historical segments were rebased; the spec's log-difference on the published index is what this pipeline uses.
